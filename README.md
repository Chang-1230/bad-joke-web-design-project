# Bad Jokes Generator

A lightweight, interactive web application that serves up random dad jokes and puns at the click of a button. Built with vanilla HTML, CSS, and JavaScript.

## Features

* **Instant Joke Generation:** Click the button to dynamically display a random joke from a curated list without reloading the page.
* **Clean, Centered UI:** Styled with CSS Flexbox, subtle shadows, and the 'Cantarell' Google Font for a clean card layout.
* **Interactive Button Feedback:** Features a subtle press-down scale animation (`transform: scale(0.98)`) when clicked.
* **Zero Dependencies:** Runs entirely in the browser with pure HTML, CSS, and JavaScript—no external libraries or build tools required.

## Tech Stack

* **HTML5:** Semantic structure and layout (`index.html`).
* **CSS3:** Flexbox centering, custom styling, and active button states (`style.css`).
* **JavaScript (ES6):** DOM manipulation, event listeners, and random array selection (`script.js`).
